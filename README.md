# 台灣公司查詢工具

透過統一編號、工廠登記編號或公司名稱，查詢台灣公司基本資料與工廠登記資訊（含產業類別）。

資料來源：[經濟部商工登記公示資料](https://data.gcis.nat.gov.tw) / [工廠登記公示資料](https://serv.gcis.nat.gov.tw/Fidbweb/)

## 使用方式

### 網頁版

```bash
pip install flask
python company_web.py
```

啟動後開啟瀏覽器至 `http://localhost:5000`

### 命令列版

```bash
python company_query.py
```

## 查詢輸入格式

| 輸入 | 範例 |
|------|------|
| 統一編號（8位數字）| `22099131` |
| 工廠登記編號 | `93A00070` |
| 公司名稱 | `台積電` |

## 顯示欄位

- 公司名稱、統一編號、資本額、登記地址、負責人
- 工廠登記編號、工廠地址、組織型態、登記狀態
- 產業類別（第11版）、主要產品
